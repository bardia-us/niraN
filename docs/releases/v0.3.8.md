## English

### New and improved
- Integrated animated Liquid Glass menus and controls, with readable text and a lighter performance-mode fallback.
- Refined the customizable Home layout, traffic display, log panel, window-size limits, theme defaults and short pop feedback.
- Added per-protocol proxy-core selection: Xray by default; sing-box for compatible profiles. TUN remains an independent setting.
- Local networks and local DNS always bypass the VPN; Iran and additional bypass rules remain configurable.
- Improved Windows optional/mandatory updates, recovery of verified downloads and bilingual What's New notes.

### Fixes
- Menu items now retain their subtle hover highlight until the mouse leaves, including after focus/input-mode changes.
- Short action menus and subscription usage no longer scroll unnecessarily; clicking the usage bar replays its fill animation.
- Added compact auto-dismissing operation messages and increased spacing between latency and server action buttons.
- Successful subscription refresh restores the subscription's original order instead of keeping a previous ping sort.
- Serialized server mutations and core shutdown to address crashes during rapid ping/sort/subscription refresh operations.
- Logs support manual text selection and copying; their hover highlight is clipped to the list rather than bleeding into the header.
- Shader preparation no longer blocks the first Flutter frame; Settings can scroll behind the frosted title bar. Startup/performance still depend on the system.

### Downloads
- **Setup:** installs or updates niraN while retaining existing configuration and user data.
- **Portable ZIP:** extract the complete folder, then run `niraN.exe`.
- Version: **0.3.8, build 12**. Xray remains the default; TUN and System Proxy are not enabled automatically.

## فارسی

### امکانات و بهبودها
- منوها و کنترل‌های Liquid Glass با انیمیشن نرم، متن خوانا و حالت سبک‌تر برای Performance Mode اضافه شدند.
- چیدمان قابل شخصی‌سازی Home، نمایش ترافیک، لاگ، محدودیت اندازهٔ پنجره، پیش‌فرض تم و صدای کوتاه pop بهبود یافتند.
- انتخاب هسته برای هر پروتکل اضافه شد؛ Xray پیش‌فرض و sing-box برای کانفیگ‌های سازگار است. تنظیم TUN مستقل باقی مانده است.
- شبکه و DNS محلی همیشه مستقیم‌اند؛ بای‌پس ایران و قواعد اضافی قابل تنظیم‌اند.
- آپدیت اختیاری/اجباری ویندوز، بازیابی فایل دانلودشده و تأییدشده و What's New دوزبانه بهبود یافتند.

### رفع باگ‌ها
- رنگ ملایم hover گزینه‌های منو تا خروج موس باقی می‌ماند؛ تغییر حالت فوکوس/ورودی آن را محو نمی‌کند.
- اسکرول اضافهٔ منوهای کوتاه و مصرف ساب حذف شد؛ کلیک روی نوار مصرف، انیمیشن پرشدن آن را بازپخش می‌کند.
- پیام‌های عملیات کوچک و خودمحو‌شونده شدند و فاصلهٔ پینگ از دکمهٔ کنار کانفیگ بیشتر شد.
- آپدیت موفق ساب، ترتیب اصلی خود ساب را برمی‌گرداند؛ ترتیب قبلیِ مرتب‌شده براساس پینگ حفظ نمی‌شود.
- عملیات تغییر سرورها و توقف هسته صف‌بندی شدند تا کرش هنگام پینگ/مرتب‌سازی/آپدیت سریع ساب برطرف شود.
- انتخاب دستی متن و کپی لاگ اضافه شد؛ هایلایت لاگ از محدودهٔ لیست و روی هدر بیرون نمی‌زند.
- آماده‌سازی شیدر جلوی اولین فریم Flutter را نمی‌گیرد و تنظیمات زیر نوار مات‌شیشه‌ای عنوان اسکرول می‌شود. سرعت شروع و عملکرد همچنان به سیستم بستگی دارد.
